# Vault Bank

Vault Bank is a banking microservices platform with a React/Vite frontend and a NestJS/Node.js backend. The deployable components are defined in `config/service-map.txt`: `auth-service`, `account-service`, `transaction-service`, `payment-service`, `notification-service`, and `frontend`.

## Architecture

- Frontend: React/Vite, built into an NGINX runtime image with `/health`.
- Backend: five NestJS services from the `backend-service` monorepo, all exposing `/v1/health` and `/v1/metrics`.
- Local runtime: Docker Compose with PostgreSQL, Redis, RabbitMQ, Vault, and NGINX gateway.
- Secrets: local `.env` files are for POC runtime only and are ignored by Git. CI/CD credentials must live in Jenkins Credentials, Vault, or IAM/KMS.

## DevSecOps Flow

The first ten delivery phases are:

1. GitHub PR and protected branch workflow.
2. Jenkins Multibranch Pipeline checkout and deterministic quality gates.
3. TruffleHog current-tree and full-history secret scans.
4. SonarQube/SonarCloud SAST quality gate.
5. OWASP Dependency-Check SCA.
6. Trivy filesystem, secret, and config scan.
7. Direct Docker/BuildKit image build for all six components.
8. Trivy image scan.
9. Syft CycloneDX and SPDX SBOM generation.
10. Harbor publication, digest scan, Cosign signing, SBOM attestation, and release manifest generation.

Jenkins must build from GitHub checkout, not from a manually cloned EC2 directory, and it must not use Docker Compose to build images.

## Local Verification

```bash
bash ci/scripts/validate-repository.sh
cd backend-service
npm ci --legacy-peer-deps
npm run lint:check
npm run build:all
npm test
npm run test:cov:all
cd ../frontend
npm ci
npm run typecheck
npm run build
```

Reports generated by local or Jenkins security runs are written under `reports/` and ignored by Git.

## No-Secret Policy

Never commit `.env` files, private keys, API tokens, Jenkins credentials, Vault tokens, signing keys, scan reports containing secrets, or generated SBOM artifacts. Verified secret findings block the pipeline and must be revoked, rotated, purged from history when needed, and re-scanned.
